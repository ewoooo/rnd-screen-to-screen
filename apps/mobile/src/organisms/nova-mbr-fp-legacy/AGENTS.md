# NOVA-MBR-FP Legacy OGN

이 폴더의 organism은 기존 `NOVA-MBR-FP-*` 화면을 유지하기 위한 **retired legacy OGN**이다.

- 신규 화면/신규 다이어그램의 재사용 후보로 우선 선택하지 않는다.
- 새로운 MBR FP 화면을 만들 때는 `DESIGN_PATTERNS.md`, `SCREEN_STRUCTURE_PRINCIPLES.md`, 최신 `Screen.diagram.html` 표준에 맞춰 OGN boundary를 다시 결정한다.
- 이 폴더의 OGN은 기존 route 빌드와 비교용 렌더를 깨지 않기 위해 보존한다.
- 수정이 꼭 필요하면 legacy 유지 보수로 범위를 명시하고, 새로운 기준 컴포넌트로 승격하지 않는다.
