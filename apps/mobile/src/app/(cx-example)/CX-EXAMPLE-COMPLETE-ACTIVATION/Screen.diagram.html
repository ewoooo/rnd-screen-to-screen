왜곡 방지 게이트

  • Header, Content, Bottom(preset="primary-cta") rail 순서를 유지한다.
  • completionHero와 completionSummary 사이에 divider, standalone hero card, cross-sell gap을 추가하지 않는다.
  • RQRContentsDetail의 카드 표면, 제목, padding, radius를 route CSS로 패치하지 않는다.
  • `홈으로 이동`과 `데이터 옮기기`의 좌우 순서와 CTA 위계를 바꾸지 않는다.
  • Figma proof 화면에 없는 정책 ID, OGN ID, 데이터 이전 eligibility를 만들지 않는다.
