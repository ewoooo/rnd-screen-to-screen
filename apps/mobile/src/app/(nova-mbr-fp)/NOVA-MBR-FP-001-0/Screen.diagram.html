왜곡 방지 게이트

  • AppScreen rail 보존: Header(‹ + 약관 동의), scroll Content, fixed Bottom(preset="primary-cta"). CTA는 Content 마지막 section 금지.
  • 화면 Primary 1개: 다음만 Primary(Bottom). guardian-input 발송/guardian-result 재요청은 Content 내 보조 위계(UXPT_BTN BTN_4).
  • 레이아웃 보존(최우선): guardianInput은 mounted-hidden — visible=false 시 divider/spacing 점유 0. guardianResult는 out-of-state — 초기 wire 미렌더. 조건부 정책 정보가 기본 레이아웃을 늘리지 않음.
  • divider 의미 분리: section 사이 4px = SectionDivider; section/카드 내부 행 사이 1px = Divider(type="contents"). FieldStack gap으로 contents divider 대체 금지.
  • typography distortion 금지: termAgree 약관에 모두 동의만 강조(first-row-only). 모든 동의 행을 sectionTitle화 금지(controlLabelScale matches-reference).
  • 인라인 에러 보존: 필수 약관 미동의/법정대리인 실패/만료 안내는 해당 영역 인접(UXPT_ERR ERR_1). 상단 통합 알림 금지. error copy는 policy-core error copy 원문 사용.
