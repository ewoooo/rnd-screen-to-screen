# Theme aliases

`theme-aliases.css`는 light / dark 두 색상 스코프를 `data-theme="light|dark"` selector로 묶어 컴포넌트 alias(`--component-*`) 와 의미 alias(`--semantic-color-*`)를 같은 변수 이름 하나로 통일합니다.

상단 툴바의 테마 토글로 light / dark를 전환해 보세요. 같은 토큰이 다른 primitive를 가리킵니다.
