# VOT_DEF — 서비스 가치 기반 라이팅 원칙

---

## VOT_DEF_1 — T Voice 도출 배경

### SV — Service Voice

| 항목 | 내용 |
|------|------|
| **핵심 UX Concept** | Readable, Less Effort |
| **목표** | 고객의 상황을 가까이서 인식하고, 혼선·판단을 줄이는 일관성 있는 커뮤니케이션 |

### 여정별 커뮤니케이션 목표

| 여정 단계 | 단계 설명 | 커뮤니케이션 목표 |
|----------|----------|-----------------|
| 전시·탐색 | 여러 선택을 비교하는 단계 | 내 맥락을 이해받는 안내 |
| 구매·전환 | 결정하고 실행하는 단계 | 오해 없는 정확한 정보 |
| CS·완료 | 결과·문제를 확인하는 단계 | 끝까지 챙겨주는 신뢰의 응답 |

### Service Core Value

| Value | 설명 |
|-------|------|
| **Borderless Experience** | 고객의 여정을 읽어, 경계없는 경험을 만든다 |
| **Intent-Based Experience** | 고객의 성향을 읽어, 의도 기반의 경험을 만든다 |
| **Frictionless Experience** | 고객이 필요로 하는 것을 읽어, 마찰 없는 경험을 만든다 |
| **Engaging Experience** | 고객의 관계를 읽어, 참여하는 경험을 만든다 |

## VOT_DEF_2 — 보이스 성격

### VA — Voice Attribute

> "나를 잘 알고, 분명하게 전하고, 끝까지 책임집니다."

고객 개개인의 통신 생활을 바탕으로, 최적의 선택을 분명하게 제안하고 결과까지 책임지고 응답합니다.

### 보이스 포지셔닝

| 축 | 방향 |
|----|------|
| 명료한 ↔ 서술적인 | 명료한 쪽 |
| 진중한 ↔ 친근한 | 중간 (T Voice 위치) |

### SAM — Service Voice Sample

> "지훈님 패턴이 이 요금제가 32,000원 더 합리적이에요."

> "요금제를 변경해도 온가족 결합 할인은 그대로 유지돼요."

> "내일이면 어머니 데이터가 소진될 수 있어요"

## VOT_DEF_3 — 보이스 원칙

### PRI_1 — 전시·탐색: 나를 잘 아는

> 내 이용 맥락을 이해하고 있다고 느낄 수 있도록 안내합니다.

| 세부 원칙 |
|----------|
| 1-1. 먼저 고객의 이용 상황을 파악하고 반영합니다. |
| 1-2. 고객의 이용 이력과 패턴을 근거로 신뢰를 제공합니다. |
| 1-3. 선택을 유도하되 명확한 근거 기반 제안으로 안내합니다. |

### PRI_2 — 구매·전환: 분명한

> 의사결정에 필요한 정보를 정확하고 신뢰감 있게 전달합니다.

| 세부 원칙 |
|----------|
| 2-1. 핵심을 먼저, 다음 흐름을 함께 안내합니다. |
| 2-2. 적용 시점과 조건을 사용자 행동 기준으로 배치합니다. |
| 2-3. 기다리는 동안 결과를 예측할 수 있도록 합니다. |
| 2-4. 결정에 필요한 판단 기준을 함께 제공합니다. |

### PRI_3 — CS·완료: 책임지는

> 끝까지 책임진다고 느껴질 수 있도록 응대합니다.

| 세부 원칙 |
|----------|
| 3-1. 완료 상태에서는 먼저 결과를 짚고 다음 기대값을 제시합니다. |
| 3-2. 공감한 뒤 다음 행동으로 이어지는 응대를 합니다. |
| 3-3. 유리한 다음 행동을 사용자가 찾을 수 있도록 먼저 제시합니다. |
