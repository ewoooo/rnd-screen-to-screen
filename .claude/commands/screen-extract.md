# Screen Extract

Use this command for Phase 1 extraction from SB files or user-provided source material.

This command is a thin Claude Code bridge. Phase procedure and output requirements are owned by `SCREEN_GENERATION_FLOW.md` and the extract skill.

## Required Reading

Read in order:

1. `AGENTS.md`
2. `SCREEN_GENERATION_FLOW.md`
3. `.codex/skills/cx-screen-extract/SKILL.md`

## Scope

- Use the user's attached SB directory or source material as input.
- Produce the Phase 1 extraction artifact/evidence required by the SOT.
- Stay within Extract unless the user explicitly asks to continue into later phases.
- Surface missing or ambiguous source fields before handing off to Map.
