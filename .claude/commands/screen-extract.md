# Screen Extract

Use this command for Phase 1 extraction from SB files or user-provided source material.

## Required Reading

Read in order:

1. `AGENTS.md`
2. `SCREEN_GENERATION_FLOW.md`
3. `.codex/skills/cx-screen-extract/SKILL.md`

## Output

Extract and report:

- screen ID, route group, domain, task, state, CTA
- policy tags and referenced policy IDs
- OGN IDs, slots, parts, hierarchy
- source files used
- missing or ambiguous source fields

Do not create Map, Diagram, or implementation artifacts in this command unless the user explicitly asks to continue.
