# UXPT_CCC — Cross-Channel Consistency

---

## UXPT_CCC_1 — 채널 간 상태 연속성

> **패턴 태그**: Borderless · Frictionless

고객이 한 채널에서 진행한 모든 행동 이력은 다른 채널에서 동일하게 조회되어야 합니다. 이력이 채널별로 분리되면 고객은 채널을 바꿀 때마다 처음부터 다시 행동해야 하며, 서비스가 단절된 별개의 공간이라고 인식합니다.

### 규칙

| 규칙 ID | 핵심 제약 | 설명 | 예시 |
|---------|---------|------|------|
| `UXPT_CCC_1_RULE_1` | 모든 활동 이력 채널 무관 동일 조회 | 최근 본 상품, 비교 내역, 상담 이력 등 모든 활동 이력은 채널에 관계없이 동일하게 조회되어야 한다. 한쪽에서 본 내용이 사라지고, 다른 곳에는 이어지지 않으면 고객이 채널마다 처음부터 다시 탐색해야 한다. | 앱에서 본 상담 이력 → 웹·오프라인 채널에서도 동일 조회 |
| `UXPT_CCC_1_RULE_2` | 채널 이동 시 고객 정보·선택 조건 재입력 금지 | 한 채널에서 전달한 고객 정보와 선택 조건은 다른 채널에서 다시 입력하지 않아도 되어야 한다. | AI Agent에서 입력한 이름·주소·단말 포함 조건 → 앱 전환 시 동일 조건 재입력 금지 |
| `UXPT_CCC_1_RULE_3` | 동기화 불가 시 이유·대체 경로 안내 필수 | 데이터를 동기화할 수 없는 경우, 이유와 대체 경로를 고객 언어로 안내해야 한다. 동기화 이유를 알리지 않으면 고객이 의아해하거나 서비스를 이탈한다. | `'이전 상담 내역을 불러올 수 없어요. 담당자에게 다시 연결해 드릴게요.'` |

### Do / Don't

| Do ✅ | Don't ❌ |
|-------|---------|
| **채널 구분 없이 동일한 이력 조회** — 서로 다른 채널에서 비교한 상품, 최근 본 상품, 상담 이력이 동일하게 조회되어 맥락이 이어진다. | **채널마다 분리된 활동 이력** — 한 채널에서 쌓은 이력이 다른 채널에서 사라지면 고객은 채널을 바꿀 때마다 같은 탐색을 처음부터 반복해야 한다. |
| 대화 내역 채널 간 동기화 | 채널 전환 후 `'최근 대화 내역이 없어요'` 표시 |

## UXPT_CCC_2 — 외부 인터페이스 경험 정립

> **패턴 태그**: Borderless · Frictionless

외부 시스템이 삽입되거나 연동되더라도, 고객이 인지하는 정보의 위계와 경험의 결과는 일관되게 유지되어야 합니다.

### 규칙

| 규칙 ID | 핵심 제약 | 설명 | 예시 |
|---------|---------|------|------|
| `UXPT_CCC_2_RULE_1` | 외부 시스템 포함 시 정보 위계·맥락 통제 유지 | 카카오 UI 내, 삼성 플랫폼, CTA 버튼의 라벨링 등 타사 서비스와 동일한 서비스의 정보 수준을 유지한다. | 외부 플랫폼 삽입 시에도 정보 위계·버튼 구조는 본 서비스 기준 유지 |
| `UXPT_CCC_2_RULE_2` | AI 에이전트 버튼 구조·결과는 일반 화면과 동일하게 동작 | 에이전트 버튼의 라벨과 결과가 일반 화면과 다르면 고객이 일관된 행동 결과를 확신할 수 없다. 외부 인터페이스에서 노출되는 CTA 버튼의 개수·역할·클릭 이동 목적지가 앱 내 네비게이션과 동일한 기준을 따라야 한다. | AI Agent CTA `'선물하기'` → 앱 내 `'선물하기'`와 동일한 흐름으로 이동 |
| `UXPT_CCC_2_RULE_3` | 외부 시스템 안내는 콘텐츠 영역 외 별도 문구로 표시 | 해당 채널의 유용한 맥락을 해치는 인식과 과도한 고지는 금지한다. 외부 경험의 인식 시스템이 스쳐 지날 수 있도록, 드러내고 싶은 서비스를 활용해 기재한다. | 외부 시스템 안내 문구는 콘텐츠 카드 내부가 아닌 상단 별도 영역에 표시 |

### Do / Don't

| Do ✅ | Don't ❌ |
|-------|---------|
| **동일한 경험 기준 유지** — 외부 시스템이 포함되더라도 제공되는 정보의 위계, 버튼 구조, 동작 결과는 본 서비스와 동일하게 유지한다. | **외부 시스템 진입 시 시각적 단절** — 외부 환경에서 버튼 명칭이나 동작 결과가 달라지면 고객이 다른 서비스로 오인하게 된다. |
| T Agent: `'선물하기'` + `'주문하기'` (본 서비스와 동일 구조) | T Agent: `'앱에서 보기'` (단절된 동작 — 앱 재진입 요구) |

### 시나리오 — 상황별 적용 방식

| 채널 | 적용 기준 | 결과 |
|------|---------|------|
| 외부 채널 (AI Agent) | 혜택 정보 위계·CTA 구조 본 서비스와 동일 적용 | AI Agent에서 제시한 VIPS 쿠폰 → 쿠폰함에 동일 저장·조회 |
| 내부 채널 전환 후 | 외부에서 발급된 쿠폰·이력 그대로 조회 가능 | 채널을 이동하더라도 고객이 동일 이력과 혜택 서비스 이어지도록 구성 |
