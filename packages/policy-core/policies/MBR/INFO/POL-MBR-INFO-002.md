# POL-MBR-INFO-002 — 회원 가입 개인정보 입력 정책

> 정책서: NC 회원가입·탈퇴 정책서 Full v1.0 확정본
> 도출일: 2026-05-08

회원 가입 시 입력받는 개인정보 항목별 검증 규칙.

## 항목

- POL-MBR-INFO-002-03 — 아이디는 영문과 숫자만 허용한다.
- POL-MBR-INFO-002-04 — 아이디는 6자 이상 20자 이하로 입력한다.
- POL-MBR-INFO-002-05 — 비밀번호는 10자 이상 20자 이하로 입력한다.
- POL-MBR-INFO-002-06 — 비밀번호는 영문 대문자, 영문 소문자, 숫자, 특수문자 중 3종 이상을 조합한다.
- POL-MBR-INFO-002-08 — 휴대폰번호는 숫자만 11자리로 입력한다.

## 메타

- 상위 정책 그룹: PG-MBR-INFO-002
- 적용 화면: NOVA-MBR-PG-002-0 개인정보 입력
- 적용 ogn: ogn-MBR-text-field-member-info
