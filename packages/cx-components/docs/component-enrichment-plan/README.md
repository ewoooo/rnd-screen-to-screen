# Component Enrichment Plan Notes

This folder is a staging workspace for Figma MOCK SOT observations before they are applied to component README files or promoted to pattern/layout docs.

These notes are not a permanent source of truth. Use them to collect evidence, decisions, and follow-ups while analyzing Figma MOCK pages. Final decisions should be applied back to one of these places:

- component README files
- `DESIGN_PATTERNS.md`
- `SPACING_PATTERNS.md`
- `@pxds/cx-layout` docs
- `component-inventory.md`

## Structure

- `base/`: staging notes for inventory entries under `components/base/*`.
- `candidate/`: staging notes for inventory entries under `components/candidate/*`.

## Workflow

1. Record Figma MOCK observations in the matching component note.
2. Classify repeated usage as README, DESIGN_PATTERN, LAYOUT_PATTERN, ORGANISM, RQR_CANDIDATE, or INVENTORY_GAP.
3. Apply confirmed decisions to the final owning document.
4. Keep this folder as working notes only. Do not cite it as product or implementation SOT.
