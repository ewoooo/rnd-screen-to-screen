# Popup

Layout popup primitives for modal alert and confirmation patterns.

Popup is an overlay pattern boundary. It owns the blocking modal structure and action slot; visual buttons and text come from `@pxds/cx-components`. Use Popup for short confirmation/error/consent flows. If content needs scrolling or contains a list of three or more substantial options, use BottomSheet instead.

Spacing follows `DESIGN_FOUNDATION.md` and ; routes should not add local padding to force popup width, button spacing, or content gaps.
